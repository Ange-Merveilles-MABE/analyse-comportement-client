# Analyse SQL et Python du comportement client et des performances e-commerce

## Présentation du projet
Ce projet vise à analyser les données de ventes et le comportement d'achat des clients d'une plateforme e-commerce afin d'en extraire des indicateurs clés de performance (KPI).

## Technologies utilisées 
- SQL: Extraction, agrégations et jointures de données relationnelles
- Python (Pandas, Matplotlib, Seaborn): Nettoyage, analyse exploratoire et visualisation
- Jupyter Notebook: Environnement d'analyse de données

## Objectifs de l'analyse 
- Calcul du panier moyen et segmentation de la valeur client
- Analyse de la fréquence d'achat et du taux de réachat
- Identification des catégories de produits les plus rentables

## Structure du dépôt
- data/: jeu de données
- scripts_sql/: Requêtes d'extraction et d'agrégation
- notebooks/: analyses exploratoires Python
